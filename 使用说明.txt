AmpliconDesk · 16S 扩增子下游分析与出图
================================================================

一、这是什么
----------------------------------------------------------------
输入「OTU/ASV 丰度表 + 分组表」，一键完成：
  * Alpha / Beta 多样性
  * 组间差异（PERMANOVA / ANOSIM / MRPP / PERMDISP / Mantel）
  * 排序分析（PCoA / NMDS / PCA / t-SNE / UMAP / PLS-DA / RDA / db-RDA / CCA / CAP）
  * 组内异质性分析
  * 群落组成（堆叠柱、面积图、热图、Venn/UpSet、核心微生物组、三元图）
  * 差异分析（火山图、MA 图、森林图、LEfSe 风格 LDA）
  * 机器学习（随机森林、ROC、混淆矩阵）
  * 高级图形（小提琴、云雨、密度、蜂群、棒棒糖、气泡、桑基、维诺树状）
并自动生成中文结论描述与自包含 HTML 报告。


二、怎么用
----------------------------------------------------------------
1. 双击本文件夹里的  启动.bat
2. 浏览器自动打开 http://127.0.0.1:8765/
3. 文件夹自带 Python 运行时，换任何一台 64 位 Windows 电脑都能直接跑，
   不需要对方安装 Python，不需要联网。

想快速试一下：点右上角「载入演示数据」，然后点「⚡ 一键出图」。

四、常见问题
----------------------------------------------------------------
Q: 双击没反应？
A: 右键「以管理员身份运行」，或确认 runtime\python.exe 存在。

Q: 端口被占用？
A: 程序会自动顺延端口；也可手动指定：
   runtime\python.exe run.py --port 9000

Q: 提示"应用程序控制策略已阻止此文件"？
A: 这是 Windows 的 Smart App Control 在拦截未签名的扩展模块。
   把整个文件夹添加信任，或临时关闭该功能即可。

Q: 数据会不会外传？
A: 不会。服务只监听 127.0.0.1，全部计算在本机完成。

Q: 数据格式有什么要求？
A: OTU/ASV 表与分组表都支持 xlsx / xls / csv / tsv / txt。
   表的方向（行是特征还是样本）会自动识别；
   是原始计数还是相对丰度也会自动判断。
   分组表【必填】——没有分组就没法做组间比较。
