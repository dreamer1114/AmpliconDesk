01选择数据文件

支持 CSV / TSV / TXT / Excel。丰度表方向（行=特征 或 行=样本）会自动识别，无需手动转置。

丰度 / 表达表 必填
OTU/ASV 表、物种表、基因表达计数表

分组表 必填
首列=样本名，其余列=分组变量
也可以直接在下方粘贴

Kingdom…Species 多列，或单列

03分析内容

默认已勾选全部模块，直接点「开始分析」即可。也可以先用下面的快捷预设， 或者只取消不需要的模块来加快速度。

快捷预设：
16S / 18S / ITS 扩增子 OTU·ASV 表
仅当提供了分类注释表时生效。
基础模块
排序分析（可多选）
用于 db-RDA / CAP
多元统计检验（可多选）
Mantel 与 envfit 需要额外提供环境因子表（或用分组自动构造）。
多样性设置
可减少测序深度差异带来的偏差，但会损失部分数据
PERMANOVA / ANOSIM / MRPP / PERMDISP 的置换次数
统计检验
默认「自动判断」：先做 Shapiro-Wilk 正态性检验与 Levene 方差齐性检验， 再据此自动选择 t / Welch / Wilcoxon / ANOVA / Kruskal-Wallis， 并把选择理由写进结论与 hypothesis_tests.csv。
用于差异分析与事后检验的多重检验校正。
多组比较时自动执行，并输出两两比较表。
过滤与绘图选项
在至少 出现率 比例的样本中达到该计数才保留
0~1，例如 0.2 = 至少 20% 的样本中检出
0~1，例如 0.0001 = 总占比不低于 0.01%
某特征在该组至少这么多比例的样本中检出，才算"存在"
